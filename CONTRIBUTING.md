# Contributing to Qareeb

Thanks for helping improve Qareeb.

## Before you start

- Read the README and SECURITY.md.
- Never commit secrets, API keys, access tokens, or personal data.
- Keep changes focused and easy to review.
- Prefer reusable components and clear naming.

## Development

```bash
npm install
npm run dev
```

Before opening a pull request, run:

```bash
npm run lint
npm run build
```

## Pull requests

Please include:

- What changed
- Why it changed
- Screenshots for meaningful UI changes
- Testing performed
- Any environment or migration notes

Keep unrelated refactors out of feature PRs.
